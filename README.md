# LUMINA

### Lenguaje de Programación Educativo

LUMINA es un lenguaje de programación diseñado como Trabajo de Curso para la asignatura Diseño de Compiladores de la carrera de Ingeniería Informática de la Facultad Nacional de Ingeniería.

> "Un lenguaje diseñado para expresar algoritmos con claridad."

## Descripción

LUMINA es un lenguaje imperativo y estructurado orientado al aprendizaje de los fundamentos relacionados con el diseño y construcción de lenguajes de programación.

El proyecto contempla el diseño de la sintaxis y semántica del lenguaje, la definición de una gramática formal y el desarrollo progresivo de sus componentes de procesamiento.

## Características

- Declaración de variables
- Tipos entero, real, cadena y booleano
- Asignaciones
- Operaciones aritméticas
- Operadores relacionales
- Operadores lógicos
- Entrada de datos
- Salida de información
- Estructuras condicionales
- Estructuras repetitivas
